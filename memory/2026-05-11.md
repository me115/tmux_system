- Added a portable, idempotent aitask installer at `scripts/install.sh`. It installs command symlinks into `~/.openclaw/bin`, writes `thelp`, manages shell aliases/PATH, appends managed tmux shortcuts, updates Codex notify, and optionally writes Feishu/OpenClaw notification config via `--feishu-target`.
- Added `README.md` and `docs/install.md` so a copied repo can be installed on another machine with `scripts/install.sh`; documented `--no-feishu`, `--skip-*`, custom bin dir, and Feishu target/account options.
